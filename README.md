## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) (or your required runtime) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd bakedcups
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
